# Assets

Repository graphics and lightweight documentation assets live here.

The current mark is designed for GitHub README display and repository
recognition. It is a working DIALECTICA mark, not the final TACITUS brand
system.

Current assets:

- `dialectica-mark.svg`: accessible README masthead mark with title and
  description metadata.
- `capsule-stack.svg`: capsule layer stack.
- `agent-build-flow.svg`: source-to-capsule build flow.
- `ontology-factory.svg`: capsule-specific ontology blueprint flow.
- `embedded-graph.svg`: embedded graph explanation.
- `research-ledger.svg`: research-to-implementation memory loop.
