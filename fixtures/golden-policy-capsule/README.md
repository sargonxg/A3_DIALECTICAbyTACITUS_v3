# Golden Policy Capsule Fixture

This fixture is the first executable DIALECTICA contract target.

It is synthetic and contains no private documents. Its purpose is to prove that
DIALECTICA can load, validate, inspect, and later compile a PRAXIS Capsule with
sourceability, temporality, embedded graph structure, reasoning devices,
human-gated language, agent guidance, review state, rights, and marketplace
metadata.

The active bundle is under `expected-bundle/`.
