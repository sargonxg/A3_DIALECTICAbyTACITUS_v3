# Operations

Available verbs: seek, understand, connect, critique, improve, apply_device, diff, compose.

Use `claims.jsonl`, `graph.jsonld`, `episodes.json`, and `evidence/sources.jsonl` for source-cited reasoning. Use `graph/ladybug/capsule.lbug` for read-only embedded graph traversal, neighborhoods, and PRAXIS graph previews.

Any agent-proposed claim must enter as T3 and pass human review before promotion.
